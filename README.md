As part of a real-world industrial data analysis task, this analyzes temperature fluctuations inside chillers or refrigeration units—an essential requirement in industries such as food logistics, pharmaceuticals, and vaccine transport. Sudden temperature spikes in these environments can lead to product spoilage, safety risks, and energy inefficiency.

This Python program combines real-world temperature sensor data with door open/close activity to uncover critical operational insights. It identifies when and how often spikes occur, examines whether door activity contributes to those spikes, calculates how long it takes for the temperature to recover after a spike, measures how quickly the temperature responds after door movements etc.

The results are compiled into a structured Excel report that includes detailed summaries, behavioral patterns, frequency statistics etc. These insights can aid in maintenance planning, anomaly detection, operational optimization, and energy management.

This solution is designed to run directly in Google Colab using uploaded .csv , making it accessible, portable, and easy to use without any local setup.
